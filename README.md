# Folly

Folly is a browser-first form builder built with React, TypeScript, Vite, and Tailwind CSS. It provides a Notion-like editing experience for creating forms, publishing shareable links, and reviewing submissions — all persisted locally in the browser.

## Features

- **Block-based form builder** with slash-menu insertion (`/`) and drag-to-reorder
- **Multiple field types** including text, choice, ranking, matrix, rating, NPS, CSAT, file upload, image, and embed blocks
- **Conditional logic** (`showIf`) to display blocks based on prior answers
- **Multi-page forms** using page break blocks and progress display
- **Theme customization** (colors, fonts, dark mode, presets)
- **Form settings** for hidden URL fields, thank-you message/redirect, and optional custom CSS
- **Public form sharing** via generated hash-route links and embeddable `<iframe>` snippet
- **Submission review** with summary stats and CSV export
- **Local persistence** using Zustand + `localStorage` (`folly-data-v1`)

## Tech Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3 + PostCSS + Autoprefixer
- Zustand state management
- React Router (hash-based routing)

## Usage

After starting the app, the main routes are:

- `#/` — marketing/landing page
- `#/forms` — form dashboard
- `#/editor/:formId` — form editor
- `#/r/:formId` — public form page
- `#/forms/:formId/submissions` — submissions viewer

Typical flow:

1. Open `#/forms` and create a form.
2. Build questions in the editor (type `/` to insert block types).
3. Use **Share** to copy a public link or embed code.
4. Open the public route (`#/r/:formId`) and submit responses.
5. View/export responses from the submissions page.

## Configuration

This project currently uses **no environment variables**.

Runtime form behavior is configured in-app (theme, hidden URL fields, thank-you redirect/button, and custom CSS) and persisted in browser storage.

## Project Structure

```text
src/
  components/         # UI, field renderers, and editor drawers/popovers
  lib/                # Logic helpers (visibility rules, layout, embeds, formatting)
  pages/              # Route pages (Landing, Dashboard, Editor, PublicForm, Submissions)
  blockCatalog.tsx    # Block definitions, grouping, search, and icons
  store.ts            # Zustand store + persistence + demo seed data
  types.ts            # Core form/block/submission types and factories
```

## Deployment Notes

Because routing is hash-based (`HashRouter`), static hosting works without server-side route rewrites. Deploy the built `dist/` output generated by `npm run build`.
